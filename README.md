# FLIPSIDE

**A retro-inspired 2D arcade game by TerMorgan**

Flipside is a fast-paced, retro-inspired 2D arcade game built around a simple idea: **flip between the floor and ceiling, react quickly, and survive as long as you can.**

Designed for short, repeatable sessions, Flipside combines simple controls with progressively increasing difficulty, collectible coins, unlockable content, and a Boost mechanic that lets players push their run even further.

---

## 🎮 About the Game

In Flipside, you control a small character travelling continuously through an ever-changing environment.

Your main objective is to survive.

Switch between the **floor and ceiling** to avoid incoming obstacles, collect coins, maintain your Soul, and keep moving forward. As your score increases, the game becomes progressively more challenging, demanding faster reactions and better timing.

Every run is an opportunity to beat your previous score.

**How far can you flip?**

---

## ✨ Features

### 🌀 Flip Movement

Switch between the floor and ceiling to avoid obstacles and navigate through the level.

### ❤️ Soul System

Your Soul acts as your survival resource. Collecting coins helps restore it, while prolonged gameplay gradually drains it.

When your Soul becomes critically low, the game provides an audio warning.

### 🪙 Coins

Collect coins while travelling through the level.

Coins contribute to your score and can provide Soul recovery, making them an important part of surviving longer runs.

### 🚀 Boost

Activate Boost to temporarily increase your speed and enter a high-intensity section of gameplay.

Boosts can be strategically used to extend runs, collect additional coins, and push for higher scores.

### 🗺️ Unlockable Maps

Progress through the game and accumulate points to unlock additional environments.

Different maps introduce their own visual themes while maintaining the core Flipside gameplay.

### 🎨 Unlockable Sprites

Unlock different playable character appearances as you progress.

Sprites are primarily cosmetic, allowing players to customize the look of their character without changing the core gameplay or hitbox.

### 📈 Progressive Difficulty

The longer you survive, the more challenging the game becomes.

Difficulty gradually increases to keep each run engaging and reward players who master the game's movement and timing.

### 🔊 Dynamic Audio

Flipside features background music and gameplay sound effects, including feedback for important events such as collecting coins, Boost activation, low Soul, collisions, and movement.

Audio can be controlled through the game's settings.

---

## 🏆 Progression & Unlockables

Flipside uses a progression system based around accumulated points.

Points can be used to unlock additional content such as:

* New maps
* New character sprites
* Other progression-based content

When points are spent on an unlockable, the required amount is **deducted from the player's available points**. Purchased unlockables remain unlocked and should persist between sessions.

The progression system is designed to give players a reason to continue improving their scores and returning to the game.

---

## 🕹️ Core Gameplay Loop

The core Flipside experience is simple:

**Start → Flip → Avoid → Collect → Survive → Score → Unlock → Repeat**

Each run is intentionally easy to understand but becomes increasingly difficult to master.

---

## 🎯 Design Philosophy

Flipside is built around a few core principles:

**Simple to play**
The basic mechanic can be understood almost immediately.

**Difficult to master**
Higher scores require increasingly precise timing and decision-making.

**Short sessions**
A complete run doesn't require a large time commitment.

**Replayability**
Players are encouraged to repeatedly challenge their previous scores.

**Progression**
Accumulated points provide a long-term reason to continue playing.

**Retro-inspired presentation**
The visual and gameplay style draws inspiration from classic arcade games while using modern web-based technology.

---

## ⚡ Performance

Flipside is designed with long play sessions and mobile hardware in mind.

The game uses performance-conscious techniques such as:

* Resource reuse
* Object pooling
* Reduced unnecessary allocations
* Efficient particle management
* Reusable visual effects
* Cached rendering resources where appropriate
* Controlled particle counts
* Efficient array/object management
* Cleanup of temporary gameplay objects
* Adaptive rendering quality where necessary

The goal is to maintain smooth gameplay without unnecessarily sacrificing visual quality.

Resources should be **reused whenever possible rather than repeatedly created and discarded**, helping reduce garbage-collection spikes and memory buildup during extended runs.

## 📱 Platform

Flipside is designed to run as a lightweight web-based game and can be packaged for Android using a WebView.

The game is also structured with compatibility for playable web-based environments such as YouTube Playables.

---

## 🛠️ Technology

Flipside is built using web technologies, with the core game implemented using:

* HTML
* CSS
* JavaScript
* HTML5 Canvas
* Web Audio API
* Android WebView integration

The Android version uses a native Java `MainActivity` to host the game inside a fullscreen WebView.
